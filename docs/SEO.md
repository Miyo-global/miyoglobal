# SEO guide

How miyoglobal.com stays indexable on production and invisible everywhere else, and the checklist every page must meet.

## Environments

| Host | Branch | Vercel project | `NEXT_PUBLIC_ENV` | Indexed |
|---|---|---|---|---|
| www.miyoglobal.com | `main` | `miyoglobal` | unset (`production`) | yes |
| staging.miyoglobal.com | `staging` | `miyoglobal-staging` | `staging` | no |
| beta.miyoglobal.com | `beta` | `miyoglobal-beta` | `beta` | no |

Any value of `NEXT_PUBLIC_ENV` other than `production` sets `NOINDEX` (`src/lib/seo.ts`). With `NOINDEX` on:

- `/robots.txt` serves `User-agent: *` / `Disallow: /`.
- `/sitemap.xml`, `/pages-sitemap.xml` and `/posts-sitemap.xml` return 404.
- Every page carries `<meta name="robots" content="noindex, nofollow">` (root layout).
- Google Tag Manager is not loaded (`src/components/google-tag.tsx`).

Independently of the flag, `src/proxy.ts` sends `X-Robots-Tag: noindex, nofollow` on every host except `www.miyoglobal.com`, so previews and `*.vercel.app` aliases are never indexed either.

Canonical URLs are built from `NEXT_PUBLIC_SITE_URL`, so staging and beta pages are self-canonical and never point search engines at a staging URL from production.

Staging and beta deliberately have no `CRON_SECRET` (the publish cron returns 401) and no `INDEXNOW_KEY` (no IndexNow pings), and their `vercel.json` registers no cron.

## Checklist (every page)

1. Unique, keyword-researched `<title>` and meta description. No duplicates across the site.
2. JSON-LD: `Organization` and `WebSite` site-wide, `BreadcrumbList` on every inner page, `JobPosting` per role, `FAQPage` where there are FAQs, `Person` for leadership.
3. Core Web Vitals: LCP < 2.5 s, CLS < 0.1, INP < 200 ms. Use `next/image` (AVIF/WebP, correct `sizes`), lazy-load below the fold, subset fonts with `display: swap`.
4. Semantic HTML: exactly one `h1`, no skipped heading levels.
5. Canonical URL on every page (`metadataBase` + `alternates.canonical`, see `src/lib/page-meta.ts`).
6. Sitemaps are generated by the `sitemap.xml` index, `pages-sitemap.xml` and `posts-sitemap.xml` routes. Submit `https://www.miyoglobal.com/sitemap.xml` in Google Search Console and Bing Webmaster Tools.
7. `robots.txt` allows indexing on production only (see Environments).
8. Open Graph and Twitter card tags on every page with a real 1200×630 image.
9. Job pages carry the full role description, requirements and benefits. No thin or duplicate content.
10. Internal links: breadcrumbs, related roles, sector hubs.
11. Descriptive, keyword-aware `alt` text on every image.
12. Keep this file current when any of the above changes.

## Verifying a non-production environment

```bash
curl -sI https://staging.miyoglobal.com | grep -i x-robots-tag
curl -s https://staging.miyoglobal.com/robots.txt
curl -s -o /dev/null -w "%{http_code}\n" https://staging.miyoglobal.com/sitemap.xml   # 404
```
